你好，世界：为什么我要开始写博客

2026-09-01

这是博客的第一篇文章。万事开头难，先把这个"头"开了再说。

为什么突然想写博客

原因有三，按重要性排序：

  • 写作是最好的思考。很多想法在脑子里是模糊的，只有落到文字上，才会发现自己其实根本没想清楚。
  • 记录对抗遗忘。读过的书、学过的课、踩过的坑，不记录下来，三个月后就只剩"好像看过"。
  • 公开是一种监督。写在日记里没人看，容易敷衍；写成博客，至少会认真一点。

会写什么内容

不给自己设限，想到什么写什么——思考、读书、生活，随缘更新。

这个博客怎么搭的

我选择了一条最简单的路径：纯静态 HTML + CSS + JavaScript，不用任何框架和构建工具。

代码托管在 GitHub，用 Cloudflare Pages 免费部署，获得一个 *.pages.dev 免费域名。每次推送代码，网站自动更新。

越简单的技术栈，越能活得更久。博客的核心是内容，不是技术。

最后

希望几年后回看这里，能看见一条清晰的成长轨迹。也欢迎路过的人随时留言交流。

愿我们都能把思考写下来。
